## Visual MINTEQ Highlights

- **Speciation:** Visual MINTEQ speciation calculates dissolved species for a solution whose totals, pH, and temperature you enter from a lab sheet or a small study.
- **Adsorption:** Visual MINTEQ adsorption adds a surface the exercise names and shows how much of an ion stays in solution versus on that surface.
- **Humic Binding:** Visual MINTEQ humic binding brings dissolved organic matter into the same problem when the sample or the assignment includes it.
- **Titration:** Visual MINTEQ titration steps pH or added base across a range so you can see the curve instead of one lonely point.
- **Mineral Equilibrium:** Visual MINTEQ mineral equilibrium lets a selected solid dissolve or precipitate until the problem reaches the condition you asked for.

## What Is Visual MINTEQ

Visual MINTEQ is an equilibrium helper for aqueous problems used in environmental chemistry courses and in small water studies. Visual MINTEQ speciation is the problem most people run first. You type the components you were given, choose the database the lab manual names, and read the species list. A single beaker from class is a complete starting case. You do not need a plant-wide model to learn the screen.

Visual MINTEQ adsorption and Visual MINTEQ humic binding are optional layers on that same solution. Use adsorption when the exercise has a mineral surface. Use humic binding when organic matter is part of the story. Visual MINTEQ titration is the sweep: many pH values, one setup, a curve you can compare with a measured titration. Visual MINTEQ mineral equilibrium answers whether a solid should be present. Each layer should be added only when your notes mention it, so the result still matches the question that was asked.

The calm path is easy to repeat at home after lab. Build Visual MINTEQ speciation, save it, then duplicate the problem before you turn on Visual MINTEQ adsorption or Visual MINTEQ humic binding. Run Visual MINTEQ titration when you need a curve. Turn on Visual MINTEQ mineral equilibrium last, and write down which solid you allowed. That order keeps a student project and a short consulting-style check on a few samples from becoming a tangle of unnamed files.

Prerequisites: A compatible computer, concentrations from a lab or a published example you may use, and permission to run Visual MINTEQ.

1. **Prepare:** List components, pH, and temperature exactly as the sheet gives them.
2. **Run Species:** Calculate Visual MINTEQ speciation and read the dominant dissolved forms.
3. **Add A Surface Only If Asked:** Turn on Visual MINTEQ adsorption when the assignment names a surface.
4. **Add Organic Matter Only If Present:** Use Visual MINTEQ humic binding when dissolved organic carbon is part of the sample.
5. **Sweep pH:** Build Visual MINTEQ titration across the range your notes specify.
6. **Allow A Solid Last:** Enable Visual MINTEQ mineral equilibrium for one mineral you can justify, then compare it with the first speciation.
